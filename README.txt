IRP LMS Website Recreation

Files:
- index.html: Home page
- courses.html: Courses page with nine YouTube embeds
- contact.html: Contact page and front-end-only message form
- style.css: Shared responsive styles

How to run:
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

The logo and banner images use the hosted Cloudinary URLs supplied in the assignment PDF.
The contact form and Sign In button are visual/front-end only; no backend or authentication is connected.
